# Dy.MedicalRecognition

这是由 Dy 代码生成器生成的 Apron 后端骨架。

## 开始使用

1. 配置用户或组织级 NuGet 凭据，使 `dysoft.common` 源可访问。
2. 设置 `DY_DATABASE_CONNECTION` 环境变量，或在部署环境覆盖 Earthrace 配置。
3. 执行 `dotnet restore Dy.MedicalRecognition.slnx` 和 `dotnet build Dy.MedicalRecognition.slnx`。

- 数据库方言：`postgresql`
- 目标框架：`.NET 10`
- 生成目标：`skeleton`、`dto`、`domain`、`application`、`repository`、`tests`
