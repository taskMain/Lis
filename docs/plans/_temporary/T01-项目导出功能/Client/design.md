# T01 前端设计

总体范围及关键决策见 [阶段设计](../design.md)。

## 页面与交互

三个页面的版面基线：查询区行为关键字输入框加「金额状态」下拉（两个金额页同款，互认项目页无下拉）；列表上沿为配置状态页签行。三页导出按钮统一承载在配置状态页签行的右侧：互认项目页在该页页签行右侧扩展承载（页签行版面随本能力扩展）；两个金额页由共用列表视图组件在同一位置承载，三页按钮款式一致。

导出按钮门控与状态：

- 范围未就绪时禁用、零请求：三页在可信上下文缺失的整页阻断态按钮不可达（互认项目页阻断口径沿用阶段 2 Client 设计「页面与交互」与用例 C1：登录凭证缺失或组织、医院编码任一空白时整页只渲染标题与错误 Alert、不发起业务请求；两个金额页为可信组织或医院缺失的整页阻断，口径见 S3-D22 与阶段 3 用例 C15）；平台页当前选定范围未完整（组织、医院、院区未选全）时禁用；本院区页登录院区缺失时禁用（该页不整页阻断，按钮随空态禁用）。
- 与既有写门控同口径，以下两态同样禁用导出、零请求：可信组织或可信范围已变化且页面尚未应用（互认项目页的组织变更提示态、平台页的待切换提示态——此时导出所取范围与页面展示不一致，互认项目页提交已应用组织会被服务端拒绝）；读取失败或写入后刷新失败（页面数据不可靠，恢复以重试为先）。
- 导出在途：按钮进入 loading 形态并防重复点击。
- 既有写门控不因导出改变：列表读取在途禁用行内操作与写入口的既有口径不变；列表读取在途与仅行内编辑进行中（无范围变化）不限制导出（导出为只读链，不产生写冲突）。
- 按钮为标准按钮语义与可访问名称，键盘焦点顺序随 DOM 顺序。

点击导出的行为三页一致：

1. 按当前生效的服务端查询条件组装请求——互认项目页提交宿主认证上下文的当前组织与已生效关键字；平台金额页提交当前选定的组织、医院、院区与已生效关键字；本院区页提交登录院区与已生效关键字。配置状态页签与金额状态下拉的当前档位不参与请求；导出与页签档位解耦（在「停用」页签下导出得到含启用配置的全量文件）为已登记的交互口径（接受与否随设计确认一并确认）。
2. 取得字节后经共享下载模块触发浏览器保存，文件名为「页面名称 + `yyyyMMddHHmmss`（发起时刻）+ `.xlsx`」；保存动作结束后释放对象地址。
3. 失败时结束 loading、保留已有列表与筛选，不误刷新、不误报成功；错误提示由宿主统一展示，页面不解析错误响应体、不新增错误拦截或提示层。零记录业务拒绝同样走宿主提示（服务端不生成空文件）。
4. 导出动作与条件不写入本页路由查询参数（导出不是页面视图状态）。

## API 与组件

- API Client 按累计规则重生成，纳入三个导出端点（POST，响应为二进制字节体）；OpenAPI 快照与 `kiota-lock.json` 同批更新并核对来源与 `/auth/login` 排除规则。生成端只透出字节体、不透出响应头，下载名由调用方给定，响应头文件名不作权威来源（阶段 6 下载模块同款口径）。
- 三个页面的功能适配层各新增导出函数：组装导出请求（范围值取各自既有来源，关键字取已生效值）并调用生成端点，返回字节；适配层不解析错误响应体。
- 共享下载模块为迁移归并形态（T01-D9）：批次 3 把阶段 6 既有 `pages/recognitionStatistics/statisticsExportDownload.ts`（含其测试文件）迁移至 `src/shared/exportFileDownload.ts`，两个统计适配层（`recognitionUsageStatisticsApi.ts`、`sourceRecognitionStatisticsApi.ts`）的引用改为共享模块。迁移的唯一行为差异：0 字节契约错误文案由「统计导出未返回文件内容。」泛化为「导出未返回文件内容。」，随迁测试的三处文案断言同批更新；其余行为不变——字节经 `Blob` 触发浏览器保存并释放对象地址；字节缺失或为 0 字节按契约错误抛出（零记录已在服务端拒绝，空内容属契约破坏）；非 0 字节内容不校验形态、按原样触发保存。本次迁移的复用检索结论：既有候选即被迁移模块本身，归并即复用。模块迁移同批在 `.agents/instructions/frontend-application.md` 公共前端模块索引表登记（执行时单独汇报）；索引行「设计出处」登记时填「阶段 6 设计（下载模块先例）」，导出能力出处待批次 5 同步后回填 004/005，不引用本临时目录。
- 展示组件通过 props 接收视图模型与回调，导出请求编排在页面层完成；三页不新增跨页面状态。
