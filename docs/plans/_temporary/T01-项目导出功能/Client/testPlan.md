# T01 前端测试矩阵

只记录测试前计划，不记录通过结果；实际命令、截图、响应和结果进入 [阶段测试报告](../testReport.md)。环境值只引用项目环境规范。层级取值为 `Component`（组件层）与 `Host`（真实宿主），并沿用既有 `Static` 层级承载生成与构建核对（Server 矩阵的 `Static` 指静态守卫，与本处语义不同）。

| 编号 | 页面或能力 | 身份与前置数据 | 操作及边界 | 预期页面、请求和业务状态 | 层级 |
|---|---|---|---|---|---|
| T01-C1 | 互认项目页导出入口 | 医院管理员；本组织已有互认配置 | 观察列表上沿页签行右侧的导出按钮，核对位置与款式 | 按钮呈现于配置状态页签行右侧，三页款式一致；页面其余区块不因导出能力变化 | Component |
| T01-C2 | 互认项目页导出请求与在途 | 同上；已生效关键字 | 点击导出，在途期间再次点击 | 请求体为当前组织加已生效关键字，不含配置状态档位；按钮进入 loading 且在途点击不发起新请求 | Component |
| T01-C3 | 互认项目页导出成功 | 同上 | 等待保存完成 | 浏览器出现文件保存，文件名为「互认项目 + `yyyyMMddHHmmss` + `.xlsx`」；打开文件核对九列列集、行集与列表一致（含启用与停用配置） | Component |
| T01-C4 | 导出失败恢复 | 同上；构造业务拒绝、网络失败，以及共享下载模块收到 0 字节或非法内容 | 分别点击导出或注入异常内容 | loading 结束、已有列表与筛选保留、不误刷新、不误报成功；无页面级错误层，宿主统一提示；0 字节内容按契约错误处理、不产出损坏文件；非 0 字节内容不校验形态、按原样触发保存；页面状态恢复 | Component |
| T01-C5 | 平台金额页导出 | 平台管理员；选定范围已有配置与金额数据 | 选定组织/医院/院区并生效关键字后点击导出；另核对范围未选全状态 | 请求体为选定三值加关键字；文件名为「互认项目金额维护 + 时间戳 + `.xlsx`」；十列列集正确，未配置金额单元格为空、金额状态「未配置」；范围未选全时按钮禁用、零请求 | Component |
| T01-C6 | 本院区金额页导出 | 医院管理员；登录院区已有配置 | 点击导出；另核对登录院区缺失状态 | 请求体为登录院区加关键字；文件名为「本院区互认项目金额 + 时间戳 + `.xlsx`」；列集与取值同 T01-C5；院区缺失时按钮禁用、零请求 | Component |
| T01-C7 | 导出与页面其他状态共存 | 行内编辑进行中、配置状态页签非「全部」、列表读取在途、可信范围已变化且页面尚未应用（互认项目页组织变更提示态／平台页待切换提示态）、读取失败或写入后刷新失败 | 在各状态下分别发起导出；导出在途时切换页签 | 导出请求不受页签档位影响；导出在途不阻塞列表读取与行内编辑；可信范围已变化未应用与读取失败两态下按钮禁用、零请求（与既有写门控同口径）；既有写门控（读取在途禁用行内操作与写入口）不因导出改变；导出不写本页路由查询参数 | Component |
| T01-C8 | 宿主真实验收 | 宿主登录 + 菜单以已授权账号分别进入三页 | 三页各完成导出成功与零记录拒绝（输入不命中关键字后导出）两条链路 | 真实宿主链路下文件保存、文件内容与宿主统一提示均正确；零记录拒绝不产生文件下载；本地直达不替代本条。宿主面不可构造时按降级口径记 `Blocked` 并以 T01-V6 应用层证据为准 | Host |
| T01-C9 | API Client 生成面 | 无 | 累计重生成并核对 | 三个导出端点入口齐全且返回二进制；阶段 1~6 已交付接口保留；`/auth/login` 持续排除；OpenAPI 快照与 `kiota-lock.json` 同步更新、来源与排除规则核对通过；包 typecheck/build 通过，无无关路径与残留差异 | Static |
| T01-C10 | 三页阻断态导出不可达 | 三页各自的可信上下文缺失装配（互认项目页登录凭证缺失或组织、医院编码空白；两个金额页可信组织或医院缺失） | 分别进入三页并观察导出按钮 | 页面整页只渲染标题与错误 Alert、不发起业务请求、不渲染列表区，导出按钮不存在（阻断分支在页面早退路径上，由构造保证；两个金额页的阻断行为本身已由阶段 3 用例 C15 覆盖，本用例断言导出按钮不随之可达） | Component |
