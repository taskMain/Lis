# 01: 统一宿主会话快照与读取顺序

**What to build:** 用户切换宿主工作身份后，页面、Context、共享钩子及提交复核立即使用同一份有效会话；迟到请求、卸载和重新挂载均不能恢复旧身份。真实读取失败按照前端设计暴露，正常生命周期取消得到准确处理。

**Blocked by:** 无前置票据。执行前按项目规则核定设计确认、实施授权、当前修改和实际影响范围；真实宿主验证另需有效环境及两个可切换工作身份。

**Status:** 实施已完成（验收清单全部勾选，依据本阶段根报告的实际证据维护）；阶段收口：`Complete`（2026-10-27 负责人明确批准；完成确认不等于发布批准）

- [x] 有效 SDK 同步异常和异步拒绝保留原始失败值，清空身份并通知订阅者；React 快照读取抛出原值，命令式读取返回 null。SDK 自身 AbortError 不按正常取消吞掉，内部初始化无未处理 rejection。
- [x] 迟到失败不清除新身份；仍有订阅时有效宿主事件可清除失败，全部释放后由重新挂载初始化恢复。测试使用测试边界观测错误，生产错误处理遵循既有设计。
