- C1（宿主登录与装载）、C2（会话字段）、C8（请求鉴权）：组件面证据在 `src/session/HostSessionContext.test.tsx`（账号与显示名、组织层级映射、匿名不显示旧身份、身份切换丢弃迟到快照、卸载释放订阅）与 `src/contexts/ApiClientProvider.test.tsx`（宿主适配器携带 `baseUrl` 与 `targetAppCode`）；宿主面证据待 IAM 基座完成子应用登记后执行。

## 票 05 覆盖说明

- C3（页头范围条）：`src/components/CurrentScopeBar.test.tsx` 覆盖三级名称齐全、某级名称缺失显示「未知」、范围查询失败显示「未知」、超长名称单行省略与 Tooltip 全文、匿名零请求；页头文本不含任何组织实例标识。
- C4（平台入口范围选择器）：`src/components/OrganizationScopeSelector.test.tsx` 覆盖选项来自范围查询、医共体 → 医院 → 院区联动、选中值为组织业务编码、`selectFirstOption` 首项回调；页面侧 `ReportManagement`、`RecognitionAmounts`、`statisticsBoard` 用例继续覆盖范围切换后的请求与结果刷新。
- C5（本院入口范围）：选择器固定组织与固定医院两种形态已在同一组件用例覆盖（本院入口只渲染医院与院区，院区限制在可信医院内）；页头范围条由 C3 覆盖。报告页与金额页可信范围均已改读宿主会话（票 07/08）；宿主走查随页面接线执行，本票不宣告 C5 宿主面通过。
- C6（身份切换）：`OrganizationScopeSelector.test.tsx` 与 `CurrentScopeBar.test.tsx` 覆盖 `sessionVersion` 推进后重新装载/重算，以及旧会话迟到响应不覆盖新会话；真实工作身份切换的宿主走查待页面接线后执行。
- C7（组织类型缺失与停用）：选项由服务端排除未配置类型与停用节点，选择器对未配置数量单独提示；读取失败给出重试入口并在重试成功后装载选项。停用节点由后端查询覆盖（票 04 的 V8），本票不重复构造。
- 本轮验证：`pnpm -F dy-medical-recognition lint` → 0；`test` → 846 通过 / 2 跳过；`build` → 0 错误。逐项证据见 [阶段测试报告](../testReport.md)。
