### 调用点结果

| 调用点 | 结果 |
| --- | --- |
| 认证与当前人 | 由 `IamApronOpenApiModule` 与 `ICurrentIamContext` 提供；`current-session` 返回当前人与三层组织编码 |
| 业务请求鉴权 | 宿主内由应用令牌适配器签发；`getApplicationToken` 取 `targetAppCode = medical-recognition`，未签发时不发业务请求 |
| 组织范围 | 范围查询按当前租户读取 IAM 组织树，输出组织业务编码与名称；父子关系取 `parentOrganizationId`，层级类型取 `OrganizationType.Code` |
| 平台参数 | 由本应用 `mrec_platform_parameter` 按编码读取，缺失、停用或取值非法按业务拒绝处理 |
| 组织树查询接口 | 接受带 `$id` 的序列化请求体；同租户存在重复业务编码时按存在性、类型与可定论父子归属校验 |
