## 改动点（全部为纯前端本地行为，不动后端契约、不动 API 请求）

### 1. 筛选条（S1-D36）

- 编码、名称两个 `Input` 合并为单一关键字框（placeholder「编码或名称」），同时按 `Code`/`Name` 字面包含匹配（复用 `matchesText` 语义，大小写不敏感）。
- 状态 `Segmented`（全部/启用/停用）改为 `Checkbox`「显示停用」，默认勾选；勾选=显示全部、不勾=仅显示启用（仍按项目自身 `IsValid`）。
- 「重置」改为 `type='text'` 小号按钮，紧跟条件组；条件组整体左对齐一行，不再孤立铺到最右。
- `ItemFilter` 类型相应改为 `{ keyword: string; showDisabled: boolean }`，同步更新 `EMPTY_ITEM_FILTER`、`filterItems` 纯函数及全部相关用例。
- 重置语义：清空关键字并恢复「显示停用」勾选，不改变左侧任何状态。

### 2. 列表固定高度（S1-D37）

- 列表卡片固定高度（与树区域齐平、撑满剩余视口）、加外边框；表格 `scroll` 增加 `y` 使表体内部滚动，行数超出时不再撑高页面。
- 行数变化与空态时卡片高度与汇总条位置不动；≤960 响应式形态同口径。

### 3. 树 Tooltip（S1-D38）

- 仅当被截断时才挂 Tooltip（量宽判断，如 `scrollWidth > clientWidth` 的小组件）；完整可见的名称不挂。
- `mouseEnterDelay={0.5}`，避免扫过即弹与遮挡邻行。

### 4. 状态合并列（S1-D39）

- 删除「状态」「当前有效」两列，合并为一列「状态」：全链路启用显示绿色 `有效`；否则显示 `无效`（悬停 Tooltip 给原因，复用 `ineffectiveReasons`）；数据不完整显示 `未知`。
- 派生判断仍用 `isItemEffective`，业务语义不变；筛选仍按项目自身 `IsValid`。

### 5. 删除类型列（S1-D40）

- 移除表格「类型」列及仅服务该列的死代码；枚举文案来源规则不再涉及列表列。

### 6. 滚动条溢出才显示（S1-D41）

- antd Table 设 `scroll.y` 后表体容器默认恒显滚动条（`overflow-y: scroll`），项数不足时也显示；以样式覆盖为 `overflow-y: auto`，仅内容溢出时才出现滚动条。
- 纯样式覆盖，不改表格行为与列定义；项少时滚动条占位释放导致的列宽轻微变化属共性取舍，不做恒留占位。
