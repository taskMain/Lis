# 后端设计

总体范围与关键决策见 [阶段设计](../design.md)。本阶段不新增业务契约、命令与事件，核对对象为阶段 1–6 已交付的后端能力。

## 领域与契约

- 无新增聚合、命令、事件与读模型；无写用例事务表与 Command-Event 表。
- S7-D8 为经确认的口径修订（患者联系电话原值展示），仅推翻报告读模型电话字段的脱敏处理，展示字段与布局不变，不属 S7-D4 分流所指的核对发现问题。
- 枚举、分页、异常语义沿用既有交付口径，不新增机制。

## 数据与集成

- 无新表、无迁移、无新索引。
- 核对面：阶段 1–6 已交付 SQL/索引与各自设计一致（如金额表无双版本字段、导出语句不扩大范围）。
- 库前预校验抽查（S7-D9）覆盖全部写命令：目录维护（分类/分组/标准项目）、互认配置启停与可互认时间、金额保存、报告与版本提交、作废、处理结果提交、引用结果提交。判定口径：业务键冲突、归属不存在、状态非法、值域越界等可在库前发现的问题有显式校验并抛业务异常；数据库错误原样抛出，无包装、无加工、无专用异常类型。
- 外部依赖（组织服务、参数服务、权限系统）在收口批次做健康核对，失败语义沿用既有交付口径。
