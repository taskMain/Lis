# 04: 互认配置查询与目录停用说明

**What to build:** 提供当前组织的互认项目配置查询，实时关联标准目录资料，并准确表达目录停用原因、配置自身状态、空结果和稳定排序。

**Blocked by:** 01 组织上下文与事件机制取证；02 互认配置公共契约与生成物整理

**Status:** ready-for-agent

- [ ] 按可信组织范围过滤配置，拒绝越权组织查询，不降级为空集合。
- [ ] 支持标准项目编码和配置状态筛选，不增加未经确认的名称、分类、分组或类型筛选。
- [ ] 实时关联标准项目名称、类型、分类和分组，不在互认配置中重复保存目录属性。
- [ ] `UnavailableReason` 按分类、分组、标准项目顺序返回单一停用原因；目录全部启用时返回 `null`；配置自身停用不占用该字段。不构造目录资料缺失等非正常业务数据。
- [ ] 按标准项目编码升序排序，不分页，空结果返回空集合；不构造同编码或相同 ID 数据验证附加排序。
- [ ] 查询语句归入既有查询 SqlMap，使用独立查询 scope `MedicalRecognitionReportQuery`；不得放入互认项目实体 SqlMap。

**Verification and evidence:**

- [ ] 先建立查询契约/投影失败证据，再实现并精确复测。
- [ ] 覆盖 V12-V14、V19-V23；记录组织过滤、原因优先级、空值、排序和异常边界到阶段 `testReport.md`。
- [ ] 按项目现行规范完成必要检查，证据归档到阶段 `testReport.md`。
