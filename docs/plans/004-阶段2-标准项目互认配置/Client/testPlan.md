# 阶段 2 前端测试矩阵

| 编号 | 页面或能力 | 前置数据 | 操作及边界 | 预期 | 层级 |
|---|---|---|---|---|---|
| C1 | 组织加载 | 可信组织 | 进入页面、切换组织 | 只显示当前组织配置 | Component |
| C2 | 目录选择 | 当前有效目录 | 选择分类、分组、项目 | 只能选择最底层项目 | Component |
| C3 | 已配置项目过滤 | 当前组织通过正常新增流程已有启用或停用配置 | 打开新增选择器 | 已配置项目（含停用配置）隐藏；不构造重复业务键数据 | Component |
| C4 | 新增配置 | 有效项目 | 正常新增和非法天数 | 成功默认启用、关闭弹窗、重载列表及选择数据，刚创建项目不再可选；保留组织及筛选，非法输入零写请求 | Host |
| C5 | 并发重复配置 | 两个页面在创建前均加载同一组织的当前有效项目 | 两个页面分别通过正常新增流程提交同一项目 | 首次成功；后到请求收到统一业务错误，表单输入和弹窗保留，列表不因失败刷新；不绕过页面或直接写库构造重复数据 | Host |
| C6 | 修改时间 | 已有配置 | 正常、同值、非法输入 | 成功刷新；失败保留输入 | Component/Host |
| C7 | 停用后修改 | 停用配置 | 修改时间 | 允许修改，不改变停用状态 | Host |
| C8 | 启停确认 | 已有配置 | 取消、关闭、确认 | 前两者零写请求；确认只改自身状态，成功重载当前组织列表并保留筛选 | Component/Host |
| C9 | 目录停用操作 | 配置先通过正常流程创建并启用，目录任一层再通过独立停用操作形成停用状态 | 读取、修改时间、停用、重新启用 | 显示目录原因；修改时间和停用成功；重新启用被后端拒绝且状态不变；保留操作入口，不禁用整行 | Host |
| C10 | 组织切换竞态 | 两个组织 | 切换并制造迟到响应 | 旧响应不得污染新组织 | Component |
| C11 | 查询失败恢复 | 查询失败 | 重试 | 保留原数据，禁止写入 | Component |
| C12 | 宿主入口 | 菜单和身份 | 登录后点击菜单 | 页面从宿主真实进入 | Host |
| C13 | 页面首次加载 | 可信组织、可读取目录 | 从宿主菜单进入页面 | 自动加载当前组织配置和新增选择数据；加载期间禁止写操作 | Component/Host |
| C14 | 手动刷新 | 当前组织已有数据 | 点击刷新并制造加载中状态 | 重新加载配置和选择数据；刷新期间禁止写操作 | Component |
| C15 | 同组织读取失败 | 当前组织已有有效数据 | 查询失败、重试 | 保留旧数据，进入不可操作失败状态；重试成功后恢复操作 | Component |
| C16 | 组织切换清理 | 两个授权组织 | 切换组织 | 清空旧列表、选择、筛选和弹窗，旧请求取消或失效 | Component |
| C17 | 组织切换读取失败 | 两个授权组织、目标组织查询失败 | 切换组织并加载失败 | 不进入目标组织可操作状态，不允许误操作旧组织数据 | Component/Host |
| C18 | 未保存切换确认 | 未保存编辑或新增内容 | 切换组织、取消或确认 | 取消保留内容；确认才清理并切换 | Component |
| C19 | 写入期间防重复 | 可写配置 | 连续点击提交或启停 | 只产生一个写请求，按钮保持提交中状态 | Component |
| C20 | 同值保存 | 已有配置 | 保存相同可互认天数 | 正常发送修改请求，成功后关闭并刷新 | Component/Host |
| C21 | 写成功刷新失败 | 写请求成功、随后查询失败 | 新增、修改或启停 | 写入成功不改判为失败；页面进入刷新失败阻断态，可重试 | Component/Host |
| C22 | 累计 Client 契约 | F01 已交付、阶段2稳定契约 | 生成前后检查清单和锁文件 | 保留 F01，加入阶段2，排除后续接口和 `/auth/login`；入口和类型完整 | Static/Build |
| C23 | Request/ReadModel 适配 | 后端契约含 nullable 和 enum | 检查创建、查询两种请求及响应映射 | 创建 Request 不提交组织编码/项目ID；查询 Request 提交所选组织编码且由后端校验范围；ReadModel无排除字段，nullable/enum不退化 | Component/Typecheck |
| C24 | 生成入口保护 | 既有生成入口、配置和锁文件 | 检查生成前后受控文件 | 不手改Kiota生成模型；受保护手写src/index.ts按实施约定恢复并核对；锁文件指向包内稳定OpenAPI，保留auth/login排除，无临时来源或无关端点 | Static |
| C25 | 不分页风险触发 | 真实宿主环境 | 记录可复现卡顿、请求超时或内存问题 | 仅有真实可复现问题时提出分页契约；无问题不新增分页 | Host/Evidence |
