# 阶段 2 前端测试矩阵

| 编号 | 页面或能力 | 前置数据 | 操作及边界 | 预期 | 层级 |
|---|---|---|---|---|---|
| C1 | 组织加载 | 可信组织 | 进入页面、切换组织 | 只显示当前组织配置 | Component（组件层用例在 `RecognitionProjects.test.tsx`：「C1：查询只提交 token 携带的可信组织编码，不带筛选、不取 URL 或本地存储」「可信组织缺失或为空白时进入不可操作状态，且不发起任何请求」，以及「提交前组织复核取现值」三例：「宿主换组织凭证但页面尚未重渲染时，提交零写请求、保留弹窗与输入并给出原因」「提交时读不到可信组织范围时同样零写请求并由页面给出阻断原因」「可信组织经历「可用、不可用、同一组织」后提交仍会发出写请求」）；宿主（2026-09-16）见 [testReport.md](../testReport.md) 的"宿主验收（2026-09-16，第三批后重取）"节（首次加载与组织编码） |
| C2 | 目录选择 | 当前有效目录 | 选择分类、分组、项目 | 只能选择最底层项目 | Component |
| C3 | 已配置项目过滤 | 当前组织通过正常新增流程已有启用或停用配置 | 打开新增选择器 | 已配置项目（含停用配置）隐藏；不构造重复业务键数据 | Component |
| C4 | 新增配置 | 有效项目 | 正常新增和非法天数 | 成功默认启用、关闭弹窗、重载列表及选择数据，刚创建项目不再可选；保留组织及筛选，非法输入零写请求 | Component/Host |
| C5 | 并发重复配置 | 两个页面在创建前均加载同一组织的当前有效项目 | 两个页面分别通过正常新增流程提交同一项目 | 首次成功；后到请求收到统一业务错误，表单输入和弹窗保留，列表不因失败刷新；不绕过页面或直接写库构造重复数据 | Host |
| C6 | 修改时间 | 已有配置 | 正常、同值、非法输入 | 成功刷新；失败保留输入 | Component/Host（Component 层用例在 `RecognitionProjects.test.tsx`：「修改弹窗回填当前值，非法输入零写且弹窗保留，同值也照常提交」「停用配置仍可修改时间，且表格与弹窗显示目录停用原因」「弹窗打开期间后台刷新交付新值时，弹窗取当前行取值而不是打开时的快照」）；宿主（2026-09-16）见 [testReport.md](../testReport.md) 的"宿主验收（2026-09-16，第三批后重取）"节（修改可互认时间） |
| C7 | 停用后修改 | 停用配置 | 修改时间 | 允许修改，不改变停用状态 | Host |
| C8 | 启停确认 | 已有配置 | 取消、关闭、确认 | 前两者零写请求；确认只改自身状态，成功重载当前组织列表并保留筛选 | Component/Host（Component 层用例在 `RecognitionProjects.test.tsx`：「取消与右上角关闭都零写请求，确认只提交目标配置与目标状态」「弹窗打开期间后台刷新改变该行状态时，启停弹窗按当前行重取动作目标」「弹窗打开期间该行离开当前行集时，启停弹窗不再渲染也不再提交」）；宿主（2026-09-16）见 [testReport.md](../testReport.md) 的"宿主验收（2026-09-16，第三批后重取）"节（启停） |
| C9 | 目录停用操作 | 配置先通过正常流程创建并启用，目录任一层再通过独立停用操作形成停用状态 | 读取、修改时间、停用、重新启用 | 显示目录原因；修改时间和停用成功；重新启用被后端拒绝且状态不变；保留操作入口，不禁用整行 | Host |
| C10 | 组织切换竞态 | 两个组织 | 切换并制造迟到响应 | 旧响应不得污染新组织 | Component |
| C11 | 查询失败恢复 | 查询失败 | 重试 | 保留原数据，禁止写入 | Component；宿主（2026-09-16）见 [testReport.md](../testReport.md) 的"宿主验收（2026-09-16，第三批后重取）"节（读取失败与重试） |
| C12 | 宿主入口 | 菜单和身份 | 登录后点击菜单 | 页面从宿主真实进入 | Host；宿主（2026-09-16）见 [testReport.md](../testReport.md) 的"宿主验收（2026-09-16，第三批后重取）"节（菜单进入） |
| C13 | 页面首次加载 | 可信组织、可读取目录 | 从宿主菜单进入页面 | 自动加载当前组织配置和新增选择数据；加载期间禁止写操作 | Component/Host（Component 层用例在 `RecognitionProjects.test.tsx`：「进入页面自动加载当前组织的配置与选择数据，加载期间禁止写操作」「读取未完成的新增入口保持禁用，完成后才可用」「组织范围不可用时不读取枚举元数据，恢复可信组织后才读取」） |
| C14 | 手动刷新 | 当前组织已有数据 | 点击刷新并制造加载中状态 | 重新加载配置和选择数据；刷新期间禁止写操作 | Component |
| C15 | 同组织读取失败 | 当前组织已有有效数据 | 查询失败、重试 | 保留旧数据，进入不可操作失败状态；重试成功后恢复操作 | Component（组件层用例在 `RecognitionProjects.test.tsx`：「读取失败保留旧数据并进入不可操作态，重试成功后恢复操作」「部分读取失败同样阻断写操作，且失败来源不覆盖已成功来源的数据」「提交在途不掩盖更强的阻断原因，读取在途则不是阻断原因」）；宿主（2026-09-16）见 [testReport.md](../testReport.md) 的"宿主验收（2026-09-16，第三批后重取）"节（读取失败与重试） |
| C16 | 组织切换清理 | 两个授权组织 | 切换组织 | 清空旧列表、选择、筛选和弹窗，旧请求**失效**（客户端契约无取消入口，只能作废迟到响应，见 [design.md](design.md) 的规范边界登记；本条不要求"取消"） | Component |
| C17 | 组织切换读取失败 | 两个授权组织、目标组织查询失败 | 切换组织并加载失败 | 不进入目标组织可操作状态，不允许误操作旧组织数据 | Component/Host |
| C18 | 未保存切换确认 | 未保存编辑或新增内容 | 切换组织、取消或确认 | 取消保留内容；确认才清理并切换 | Component（组件层用例在 `RecognitionProjects.test.tsx`：「C18：组织变化遇未保存内容先确认；取消保留内容与旧组织视图，确认才清理并切换」「后台刷新使修改弹窗的目标行消失后，组织变化不再出现未保存内容确认」） |

| C20 | 同值保存 | 已有配置 | 保存相同可互认天数 | 正常发送修改请求，成功后关闭并刷新 | Component/Host（Component 层用例在 `RecognitionProjects.test.tsx`：「修改弹窗回填当前值，非法输入零写且弹窗保留，同值也照常提交」） |
