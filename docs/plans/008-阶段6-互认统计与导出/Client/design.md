# 阶段 6 前端设计

## 页面与交互

本阶段交付四个页面，名称与菜单由本项目提供，菜单子项与授权由负责人在权限系统配置；页面不实现角色判断、不做权限二次确认，能进入页面即视为已获授权。四个页面的路由字符串在页面实现阶段确定，设计阶段只固定「四个入口、四条独立路由、四个页面、四个菜单」这一结构。四个页面复用同一套统计页组件（筛选区、汇总表、明细表、导出入口、匹配记录弹窗），差异只在取值来源与固定文案。

| 页面 | 菜单名称 | 数据范围 |
|---|---|---|
| 平台接收侧页 | 接收医院互认使用统计 | 组织、医院、院区取值随请求提交（另可选来源组织、医院、院区） |
| 本院接收侧页 | 本院互认使用统计 | 本侧组织、医院、院区恒为可信上下文（院区为登录院区）；来源医院、院区可选筛选（组织固定为可信组织） |
| 平台来源侧页 | 来源医院被互认统计 | 来源与接收两组组织、医院、院区取值随请求提交 |
| 本院来源侧页 | 本院被互认统计 | 来源组织与来源医院取可信上下文固定，来源院区为登录院区；接收医院、院区可选筛选（组织固定为可信组织） |

四个页面都从宿主登录页与宿主菜单进入，不提供本地直达入口。

**页面结构。** 接收侧页面由五部分构成：筛选区（日期范围必填；平台版接收组与来源组均含组织、医院、院区三级可选；本院版本侧组织与医院固定展示、院区为登录院区，对侧组仅医院/院区可选；互认科室、互认项目；互认医生只进明细筛选）、汇总维度单选、汇总表、明细表（明细类型单选 + 明细筛选 + 分页）、导出入口；汇总表内嵌不采纳原因次数及占比区。来源侧页面无明细类型切换与不采纳原因区，筛选区（平台版来源组与接收组均含组织、医院、院区三级可选；本院版本侧组织与医院固定、院区为登录院区，对侧组仅医院/院区可选），其余同构。匹配记录弹窗从接收侧明细行进入，展示组级信息与全部互认匹配项。

**筛选提交式（2026-10-10 修订）。** 筛选区为 `Form layout="inline"` 行内表单，查询与重置按钮在行内并排（查询按钮逐字规格 `type="primary"` + `SearchOutlined` + `autoInsertSpace={false}` + `htmlType="submit"` + 文字「查询」；「重置」为默认样式）。筛选控件改动只进入草稿条件、不发起请求；点「查询」把草稿提交为已生效条件，**一次提交同时重读汇总与明细两个区**；点「重置」清空草稿并恢复默认条件。汇总维度、明细类型是视图切换，保持即时生效、不进草稿；翻页基于已生效条件自动读取。页头不设独立刷新按钮，首次进入自动加载，手动重读经查询按钮（条件为空时提交等价于刷新）；明细区的互认医生、不采纳原因筛选并入同一草稿，由同一组查询/重置提交。

**汇总展示。** 汇总表按所选汇总维度出列：医院维度行展示医院与院区归属，院区维度行展示院区归属，互认科室维度行展示院区 + 科室 ID 与名称，标准项目维度行展示项目类型、分类、分组、编码与名称；未参与分组的维度列不渲染。行内展示提醒、采纳、不采纳、引用、同期互认率与预计节省金额；同期互认率未计算时展示「—」而非零或百分之百；不采纳原因区展示各原因次数与占比（行内不采纳为零时展示「—」）。互认科室名称取服务端返回值，页面不按 ID 自行拼接或改名。互认科室维度行的提醒与同期互认率不含未反馈项，跨维度数字不可直接对账，页面不对不同维度的数字做合计校验。

**下钻联动。** 点击汇总行的提醒/采纳/不采纳/引用数字，明细表按该维度值 + 对应明细类型**预填筛选草稿并自动提交一次**（走与查询按钮同一条提交路径，2026-10-10 修订，原直接查询口径改为草稿提交式下钻）；点击原因行，明细表加原因代码筛选；点击预计节省金额随采纳明细展示。提交后汇总与明细回到第 1 页并保留页容量。汇总数字与明细计数不一致时以后端为准并允许重查，页面不本地重算。

**明细与分页。** 明细表的归属路径按三行式展示（2026-10-10 修订，原来源组织/医院/院区、接收组织/医院/院区六个独立列合并）：接收侧明细表以「来源方」「接收方」各一列承载，来源侧明细表以「来源方」单列承载；单元格内三行——组织名、医院名、灰色小字的院区名，只显名称不显示编码，名称缺失的行显示「未知」，不回退编码（名称取服务端返回值，页面不做前端反查）。汇总表的维度列不在此列（维度是统计本身，保持按维度分组出列）。明细表使用服务端分页：提交页码与页容量，取回当页与分页信息；分页控件位于表格下方、页容量可选、显示总数、改变页容量回到第 1 页。未反馈行在提醒明细中显示「未反馈」，处理结果列留空；页面不把未反馈行本地标记为不采纳。患者姓名与证件号码按服务端返回值原样展示（S6-D9），页面不做二次处理。明细行提供只读「查看互认匹配记录」入口，弹窗展示组级信息、就诊、未反馈或已处理状态、决定主体与全部匹配项；弹窗不提供报告内容、PDF 或影像入口。

**导出入口。** 汇总区与明细区各设导出入口，分别导出汇总与对应明细类型；导出入口沿用页面当前查询条件与数据权限，导出全部记录而非当前分页；导出过程中页面进入加载态并禁用重复提交，成功后按浏览器保存文件，失败由宿主统一提示（零记录时宿主提示「当前条件下无可导出数据」，超过 10 万行上限时由宿主统一提示缩小查询条件），页面不弹本地接口错误、不误刷新列表。

**时间筛选。** 日期范围使用日期选择器，必填，提交起止日期（`yyyy-MM-dd`），页面不拼接时分秒、不写入时区偏移；不限制最大跨度，页面不做跨度本地校验。

**范围取值。** 平台页组织、医院、院区三级均可选；来源组组织、医院、院区三级均可选。本院页**不提供本侧院区选择**（2026-10-10 修订，原「本侧院区可选、为空即全院」口径作废）：本侧组织、医院、院区恒取可信上下文，请求院区参数恒为登录院区；院区为空属权限配置错误，页面不伪造院区、不做全院查询、不进入整页阻断，适配层拒绝构造请求、页面零业务请求并以空态呈现，恢复正确的权限配置后按登录院区重读；对侧组仅医院、院区可选，不渲染组织级选择器（对侧组织固定为可信组织）。本院页页头以单行纯文字展示当前登录范围的三级名称（「组织名 / 医院名 / 院区名」），不展示编码：名称超长单行省略、悬停经 Tooltip 展示全文；某级名称缺失或反查失败时该级显示「未知」，不回退编码。组织名称取自可信范围查询返回的组织名称；医院、院区名称按登录上下文编码经基础目录接口反查（与 `@dy/auth` 同源认证适配器自动携带宿主登录令牌），反查失败属接口错误、由宿主统一提示。可信组织或医院缺失（登录凭证缺失，或组织、医院编码任一空白）时页面整页只渲染标题与一条错误 Alert（带图标，文案说明无法读取当前登录组织或医院、已阻断本页查询与操作）、不渲染后续选择器、不发业务请求，不伪造组织、不降级为空值；院区缺失不进入该阻断。页面不做本地归属判断，越界选择由服务端拒绝。

**枚举展示。** 项目类型、就诊类型、处理结果、明细状态等取值中文取服务端随行返回的文本字段；筛选与表单选项使用集中缓存的枚举元数据；页面不新写中文映射表，本地兜底只用于契约字段缺失。

**加载与失败。** 页面首次进入自动加载，手动重读经查询区的查询按钮（页头不设独立刷新按钮，2026-10-10 修订）；四个页面为只读页面，失败面为汇总读取失败、明细读取失败、导出失败与弹窗读取失败四类；读取失败时保留已有数据、结束加载态，页面**不渲染错误横幅**（2026-10-10 修订，原汇总区与明细区读取失败横幅作废），错误由宿主统一提示，重试经查询按钮；已提交条件变化清空上一条件的数据与未提交筛选草稿；同一筛选条件下只采纳最后一次请求结果。

## API 与组件

使用现有 API Client 上下文，不在页面创建客户端。查询使用八个查询端点（四能力 × 平台/本院），导出使用两个 POST 端点（返回文件字节），匹配记录弹窗使用单记录端点。适配层负责把生成的请求与读模型转换为稳定视图模型：平台/本院两个版本的分支收敛在适配层，页面组件不感知请求形态差异；分页响应在适配层收敛为页面分页模型，对页码、页容量与总数做安全整数校验；导出字节在适配层转为浏览器保存（沿用 PDF 下载模式）。页面不直接扩散生成的 Kiota 类型，不把患者证件号码等敏感条件写入地址栏。

**复用与新增。**

| 类别 | 内容 |
|---|---|
| 复用 | API Client 上下文；每页一个适配层的既有约定；筛选区/表格/空态/失败态骨架；共享受控分页配置工厂（`tablePagination`）；枚举元数据缓存钩子；可信上下文接缝；PDF 下载处理模式 |
| 新增 | 统计页目录与四个页面入口、统计页组件（筛选区、汇总表、明细表、原因区、导出入口）、匹配记录弹窗组件、两个适配层（接收侧/来源侧）与视图模型、维度切换与下钻联动状态处理、导出下载处理 |
| 依赖 | 本阶段不新增前端第三方依赖；Excel 生成在后端，文件下载使用浏览器原生能力与已鉴权客户端 |

**API Client 累计生成。** 保留阶段 1–5 已交付接口，加入本阶段稳定契约（八个查询端点、两个导出端点、一个匹配记录端点），排除登录接口。生成前核对累计清单，生成后核对公开入口、请求与读模型字段、可空性、枚举、分页形状与无残留后续端点；生成会覆盖手写入口文件，生成后必须核对并恢复手写内容。

## 已接受风险

- 患者姓名与证件号码在统计页、明细与导出的展示/导出为业务原值（S6-D9），后续如需收紧按新决策处理。
- 日期不限最大跨度，超大数据量的加载时长取决于后端索引与数据量，页面只呈现加载态。
- 平台页的跨组织数据在本地环境不可构造时，真实宿主面按阶段 4 `S4-D39` 同类口径降级（应用层证据为准）。
