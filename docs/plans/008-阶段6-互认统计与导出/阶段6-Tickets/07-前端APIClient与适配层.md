# 07: 前端 API Client 与适配层

**What to build:** 让前端具备调用阶段 6 全部后端能力的地基：API Client 按累计规则重生成（加入八个查询端点、两个导出端点、一个匹配记录端点，保留阶段 1-5 已交付接口，排除登录接口），生成后核对公开入口、请求与读模型字段、可空性、枚举与分页形状，恢复被覆盖的手写入口；接收侧与来源侧两个适配层落地：平台/本院双版本请求分支收敛（本院版不提交本侧组织与医院、提交对侧组医院/院区，平台版接收侧提交两组含两组织编码供一致性校验）、分页请求内嵌 `page` 对象、分页响应用安全整数与值域校验收敛（非法响应按契约错误处理）、读模型转视图模型（枚举值+文本、未参与分组维度 `null` 兜底、患者字段原样）、导出字节转浏览器保存（沿用 PDF 下载模式，对象地址释放，失败无本地提示）。

**Blocked by:** 00

**Status:** ready-for-agent

- [ ] 生成后公开入口完整、累计范围无泄漏、无退化类型；手写入口恢复（C1）
- [ ] 无后续阶段端点泄漏、无残留占位模型（C2）
- [ ] 生成包与应用均可构建、类型检查通过（C3）
- [ ] 双版本请求映射、分页嵌套、日期原样提交、敏感条件不入地址栏（C4）
- [ ] 分页响应收敛与安全整数校验（C5）
- [ ] 分页控件配置：页容量可选值与服务端一致（1–200）、显示总数、改变页容量回到第 1 页、加载中禁用（C7）
- [ ] 读模型映射：枚举文本、维度 `null` 兜底、患者字段原样（C6）
- [ ] 导出下载处理：已鉴权取字节、按响应文件名保存、地址释放、失败无本地提示（C8）

**口径：** 后端契约以票 00 为稳定前提；本票不产生运行期证据，组件与宿主面由票 08、09 承接。页容量取值域与服务端一致（1–200）。双版本请求与范围取值口径依据 S6-D1 与 S6-D18；患者字段原样映射依据 S6-D9。
