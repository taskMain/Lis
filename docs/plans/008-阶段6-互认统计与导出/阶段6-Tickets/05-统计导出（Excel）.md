# 05: 统计导出（Excel）

**What to build:** 让统计页面能把当前查询条件下的结果导出为 Excel：七个导出类型（接收侧汇总/提醒/采纳/不采纳/引用明细、来源侧汇总/明细）经两个 POST 端点（平台/本院）发起，控制器返回 `.xlsx` 文件流；导出继承发起时的全部查询条件与汇总维度、不使用页面分页，复用统计语句先计数——零记录业务拒绝「当前条件下无可导出数据」、超过 10 万行业务拒绝并提示缩小查询条件（S6-D5 已接受收窄），两种拒绝下不返回文件响应、不产生空工作簿；导出请求按导出类型校验汇总维度子集（来源侧类型不接受互认科室维度），不采纳原因代码仅作用于接收侧不采纳明细导出；明细按匹配项一行展开、组级字段重复、带匹配记录与匹配项 ID、未反馈项进提醒明细并显示「未反馈」；汇总导出为页面汇总行同结构、按当前条件重新聚合，含不采纳原因次数及占比；文件不含完整报告结构化内容、PDF 文件标识与下载入口、影像调阅地址、院内项目编码/名称/项目映射。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 七类导出内容与口径逐项相符：明细展开、双 ID、未反馈显示、汇总导出行结构、院内项目字段不导出（V34）
- [ ] 导出继承查询条件与业务归属、不使用页面分页；越权条件按范围校验拒绝；零记录业务拒绝（V35）
- [ ] 超过 10 万行上限业务拒绝并提示缩小查询条件；上限为对 F09「全部匹配记录」的已接受收窄（S6-D5）（V36）
- [ ] 导出不含完整报告结构化内容、PDF 文件标识与下载入口、影像调阅地址（V37）
- [ ] POST 返回 `.xlsx` 文件流：Content-Type 正确、文件名为导出类型加起止日期、响应头禁止缓存；零记录与超限拒绝下不返回文件响应、不产生空工作簿（V38）
- [ ] 控制器两个 POST 动作各自绑定平台/本院请求类型并调用同一应用层导出入口，本院注入发生在应用层

**口径：** ClosedXML 内存工作簿组装的内存峰值风险已按 S6-D16 登记（AcceptedRisk）；接近上限规模的真实导出不构造，重审条件随真实业务量增长触发。
