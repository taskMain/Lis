# 01: 提供方明细四字段端到端

**What to build:** 提供方医院被互认统计与本院被互认统计的明细，每一行同时给出标准项目名称、项目类型、分类与分组；明细导出文件输出与页面一致的列；名称为空、编码缺失、分类或分组缺失时按设计口径显示。字段来自服务端随行返回，页面不回查标准目录。

**Blocked by:** None（可以立即开始）

**Status:** 已完成（2026-10-22）

- [x] 提供方明细查询响应含标准项目名称、项目类型（枚举与文本）、分类名称、分组名称四项，可空性与设计决策「S6-D25 提供方明细字段补充」（`docs/plans/008-阶段6-互认统计与导出/design.md` 关键决策表）一致
- [x] 明细语句只扩展选择列，计数语句与数据语句仍共用同一套关联、筛选与排序，不新增语句、不改变分页窗口
- [x] OpenAPI 与生成的 API Client 字段集合一致，累计生成规则与既有排除项保持不变
- [x] 明细导出的列顺序与页面明细列一致，四列取值与页面同源，导出总数与页面明细总数一致
- [x] 名称为空显示「未匹配标准项目」，编码缺失显示「—」，分类或分组缺失时该段整体省略
- [x] UML 5 的提供方明细读模型同批同步四个字段
- [x] 契约、语句与导出用例取得通过证据，「V54 提供方明细读模型字段」「V55 提供方明细语句选择列」「V56 提供方明细导出列」（`Server/design.md` 验证矩阵）逐条登记
