# 01: 请求与事件契约、读模型重建

**What to build:** 让四个接口的对外契约成型：四个请求类型（匹配查询、处理结果提交、引用详情、引用结果提交）与三个领域事件的声明就位；十个契约读模型由无类型对象重建为强类型，集合与枚举字段强类型、属性只读；匹配响应与引用详情的字段边界按设计可判定——检查所见与检查结论只在引用详情返回，匹配响应不含标本类型编码与院内标本号、不含固定的互认超期时间字段，PDF 与影像入口不携带独立有效期与一次性状态。四个请求类型分别经请求校验器断言必填与标识类型。

**Blocked by:** 00

**Status:** ready-for-agent

**外部前置：** 无（本票只改契约类型，不改运行路径）

- [ ] 四个请求类型的字段集合与设计一致：查询含患者证件类型与号码、本次来源就诊类型与院内就诊流水号，且不含挂号时间、入院时间与统一就诊时间；处理结果的科室与医生标识以字符串承载、项目数组完整提供该组全部匹配项标识与决定；引用详情不含平台患者 ID、互认匹配记录 ID、互认匹配项 ID 与互认时间；引用结果含匹配项标识、实际引用时间、科室与医生的标识与名称（标识以字符串承载），且不重复提交匹配记录 ID、本次来源就诊与互认时间（V81）
- [ ] 四个请求类型经 `MedicalRecognitionRequestValidator` 断言必填与标识类型：缺少必填被判拒绝，合法请求通过（V81；取证方式见 README 约定 13）
- [ ] 十个契约读模型均为强类型：集合与枚举字段不再是 object、属性只读（V82、V83）
- [ ] 匹配响应含记录标识与生成时间、报告公共信息与项目级内容（来源医疗机构名称由来源三值经组织路径解析点批量回填）、PDF 与影像入口；不含标本类型编码与院内标本号、不含固定的互认超期时间字段（V82）
- [ ] 匹配响应不含检查所见与检查结论（V84 的匹配响应面）
- [ ] 引用详情含报告公共上下文、检查所见与检查结论、PDF 与影像入口，且入口不携带独立有效期、不携带一次性或消费状态（V83、V84 的引用详情面）
- [ ] 三个领域事件的声明与聚合标识口径就位（无矩阵编号：属批次 0 的事件声明面，其登记断言由票 03–06 承接）
- [ ] 枚举文本在读模型上以计算属性暴露（V85 的读模型面，与票 00 共同承接）
- [ ] `git diff --check` 干净（无矩阵编号）

**口径：** 本票覆盖契约层（`Contract`）与读模型契约面；V85 在本票只承接读模型计算属性面（元数据与登记面由票 00 承接），V84 在本票承接匹配响应面（引用详情面由票 05 承接）；运行期证据由票 03–06 承接。
