### 参数严格失败语义（本轮第三批，本地参数服务替身）


本平台只有三个系统参数，取值只来自平台系统参数服务。为在不改平台配置、不改被测代码的前提下取得三类前置，本轮在本机起了一个最小 HTTP 参数服务替身（按参数编码返回取值，模式由文件切换），并把**本地**后端的系统参数代理临时指向它；共享平台配置与业务代码均未改动。替身的正常模式先与平台取值核对一致（两端点均返回成功），再分三类模式取证：

| 取值缺失 | HTTP 500「业务拒绝：未配置本院报告匹配开关。」 | HTTP 500「业务拒绝：未配置引用详情有效时长。」 |
