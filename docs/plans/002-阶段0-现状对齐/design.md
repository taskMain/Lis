# 阶段 0 现状对齐设计

本阶段是进入实际开发前的基线确认阶段，不实现业务功能。本文确定对齐范围、对齐方法、输出物与不处理范围；实施过程与结论见 [impl.md](impl.md)。阶段划分与计划原则见 [总体计划设计](../001-总体计划/design.md)。

## 目标与范围

- **目标及可验收结果**：把 SRS、后端骨架、数据库脚本、OpenAPI 与 API Client、前端页面、工具链状态与工作区状态核对到可据以决策的程度，形成后续各阶段可直接引用的现状结论。可验收结果 = 本阶段两份文档完成，且每条结论都有可复核的文件路径、命令或行号作为依据。
- **纳入范围**：
  - 后端：项目结构、目标框架与包依赖；应用契约、请求模型、DTO、枚举与值域；应用服务事务边界、操作人注入与代码风格；领域聚合、领域管理器、命令、事件与状态规则；仓储接口与实现、Earthrace SqlMap、SQL 脚本与实体的对应关系；外部依赖边界与实际配置状态。
  - API Client：OpenAPI 固化位置与接口数量；`kiota-lock.json` 状态；登录接口排除规则；入口导出完整性；生成类型的退化与空壳风险；可构建与类型检查状态。
  - 前端：微前端入口、运行时配置与 basename；认证与 API Client 上下文；当前路由、页面与布局；构建与静态检查状态。
  - 工作区状态：已有未提交变更的说明，避免后续阶段误覆盖。
- **排除范围**：不实现任何业务功能；不修 SqlMap 与仓储；不创建数据库表；不重新生成 API Client；不新增前端业务页面；不调整数据库脚本内容。
- **需求与领域模型依据**：`docs/需求规约SRS.md`、`docs/uml/`；生成物来源见 [Project Context](../../../.agents/instructions/project-context.md)。
- **前置依赖及当前确认状态**：总体计划已确认（阶段划分与计划原则已定）；后端与前端工具链可用；数据库、宿主与外部系统地址已在环境规范中确认；两个已知阻断的状态已知但修法未定。

## 设计

### 对齐范围分解

本阶段把对齐工作分成四块，每块在 [impl.md](impl.md) 中有对应的执行批次。

1. **后端范围**。核对项目结构、目标框架与包依赖；应用契约、请求模型、DTO、枚举与值域；应用服务事务边界、操作人注入与代码风格；领域聚合、领域管理器、命令、事件与状态规则；仓储接口与实现、Earthrace SqlMap、SQL 脚本与实体的对应关系；外部依赖边界与实际配置状态。

2. **API Client 范围**。核对 OpenAPI 固化位置与接口数量；`kiota-lock.json` 是否指向稳定 OpenAPI；登录接口是否保留排除规则；生成入口是否导出 client、api 与 models；生成类型是否存在退化类型、空壳模型或入口导出丢失风险；是否能构建与类型检查。

3. **前端范围**。核对微前端入口、运行时配置与 basename；认证与 API Client 上下文的接入方式；当前路由、页面、布局与业务页面缺口；构建与静态检查当前状态。

4. **工作区状态**。核对当前工作区是否已有非本阶段修改；这些修改是否影响后续阶段判断；本阶段新增文档是否与既有改动隔离。

### 对齐方法

1. 以文件路径与行号为依据逐项核对，不以印象或历史叙述代替。
2. 对可执行的验证项实际执行命令，形成工具链与构建基线；只记录真实输出。
3. 数据库现状通过只读查询核对，不执行任何写操作。
4. 差距按后续阶段归属整理，**不在本阶段内修复**；每条差距给出归属阶段与理由。
5. 已知阻断只核对状态与影响面，修法留给所属业务阶段。

### 输出物

1. 后端现状结论（含实体、表、SqlMap 与契约的对应关系）。
2. API Client 与 OpenAPI 现状结论。
3. 前端现状结论。
4. 工具链与构建、静态验证的实际结果。
5. 工作区未提交变更说明。
6. 后续阶段处理建议。

### 不处理范围

1. 不修改后端业务代码。
2. 不重新生成 API Client。
3. 不新增前端业务页面。
4. 不调整数据库脚本内容。
5. 不创建、不修改数据库表。
6. 不提交代码。

## 验收与停止条件

- **适用验证面及通过条件**：本阶段为规范阶段，验收面是文档完整性而非功能行为。通过条件 = 四块对齐范围均有结论、每条结论有可复核依据、工具链命令有实际输出、工作区变更已说明、后续阶段建议已给出。
- **环境或数据依赖**：后端构建与测试依赖本机 .NET SDK 与 NuGet 缓存；前端构建与类型检查依赖本机 Node 与 pnpm 工作区；数据库现状核对依赖只读连接。配置值引用 [Test Environment](../../../.agents/instructions/test-environment.md)，不在本文复制。
- **负责人执行迁移或其他外部动作**：本阶段无迁移动作，不执行任何数据库写操作。
- **超出授权或影响边界不明时的停止条件**：发现需要修改业务代码、重新生成 API Client、调整数据库脚本或建表才能继续核对时停止该项核对，记录为后续阶段任务，不在本阶段内执行。
