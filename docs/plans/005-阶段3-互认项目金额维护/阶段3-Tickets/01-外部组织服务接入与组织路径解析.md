# 01: 外部组织服务接入与组织路径解析

**What to build:** 让互认平台能调用外部组织服务，并把「组织 → 医院 → 院区」这条路径一次性读进来做归属校验，供后续金额保存与查询共用。本票先坐实整条后端线最不确定的依赖：新增组织服务契约包 `Dy.Base.Application.Contracts` 的引用与中央版本条目（版本与依赖口径见 `Server/design.md` 的公共契约与分层段）并实测构建通过；随后实现组织路径解析（一次批量读取组织、医院、院区，在内存校验三层的存在、启用、父子归属，并返回三级名称），以及阶段 3 四个金额入口共用的可信组织与医院解析（`TrustedScopeResolver`：令牌该层非空白即取令牌值；令牌该层缺失或空白时用当前登录用户档案补齐；令牌与用户档案在同层都提供且不一致即拒绝；补齐后该层仍为空即拒绝，不使用默认值、不降级为空值；院区不参与该解析，仍由请求提交并由组织路径校验归属）。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**外部前置：** None（包引用与实测构建是本票自身的第一个勾选项）

- [ ] 新增组织服务契约包 `Dy.Base.Application.Contracts` 引用与中央版本条目，`restore/build` 实测通过；若失败，按设计登记的两条退路先经负责人确认后选定，不自行降级为不校验归属
- [ ] 路径解析对同一批目标路径只做一次组织全量读取、按不同组织各一次医院与院区读取；调用次数不随目标行数增长（V19，计数替身断言）
- [ ] 组织、医院、院区不存在、已停用、父子归属不匹配时拒绝（V8-V10）
- [ ] 医院管理员入口在可信上下文缺少组织或医院时拒绝，不使用默认值、不降级为空值（V14）
- [ ] 组织、医院、院区的编码取外部服务的 `Id`、启用状态取 `IsValid`；类型级绑定在本票编译期确认（设计侧为元数据级核对，未逐类型复核）
- [ ] 通过本票即可复现路径解析的成功与拒绝两类结果，且不产生任何写库动作
- [ ] 先建立本票的目标失败证据或等价基线，并完成适用影响分析
- [ ] 适用测试、构建、静态检查通过；`git diff --check` 干净
- [ ] 证据（命令、输出、残余风险）记入阶段测试报告

**口径：** 本票覆盖层级为应用层（外部服务接入、路径解析与归属校验）；本票只覆盖所引用矩阵用例在该层级的证据，矩阵编号可跨批次引用，按完整用例只统计一次，只完成部分层级不记为通过。
