# 06: 累计 API Client 生成与适配层

**What to build:** 在保留阶段 1、阶段 2 已交付端点的前提下，累计生成本阶段四个稳定端点（两个金额保存、两个金额查询）的 API Client，并加一层前端适配层把生成的请求与读模型转换成稳定视图模型，页面不直接扩散生成类型。生成前核对累计端点清单，生成后核对公开入口、请求与读模型字段、可空性、枚举与无残留后续端点；`/auth/login` 保持排除。生成入口、配置与锁文件受版本控制，生成过程不提交本机路径、日志或临时文件。本票同时交付适配层测试：先建立字段映射、可空性与枚举转换的失败基线，再实现适配层。

**Blocked by:** 02（金额保存写入与事件）、03（金额查询读模型）

**Status:** ready-for-agent

**外部前置：** 包私服与生成工具可用；后端四个端点的契约稳定（票 02、03 交付）

- [ ] 净增四个本阶段端点；阶段 1、阶段 2 已交付端点保留；`/auth/login` 保持排除；包公开入口未被覆盖（C24）
