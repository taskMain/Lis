# 07: 两个页面与路由

**What to build:** 交付平台管理员页「互认项目金额维护」与医院管理员页「本院区互认项目金额」两个页面及各自路由，两页都从宿主登录页与宿主菜单进入，不提供本地直达入口。平台管理员页的组织、医院、院区三级均可切换；医院管理员页以只读方式固定展示可信组织与医院、只渲染院区下拉，可信院区缺失时不自动选中、须显式选择后才允许提交且不发空值参数，可信组织或医院缺失时给出阻断提示、不渲染院区下拉、不发出任何业务请求。列表按当前范围展示，未配置与零元必须可区分；每行提供独立的金额维护入口，弹窗录入并提交，校验不通过不发写请求，提交失败保留弹窗与输入，提交成功后关闭弹窗并整表重载；加载期间禁用写入，读取失败保留已有数据、进入不可写状态并可重试；写成功但随后的刷新失败仍按写成功呈现并提示「写入已成功，数据待刷新」，允许重试刷新；范围切换清空未保存输入与旧范围数据。本票同时交付组件层测试：先建立失败基线，再实现页面。

**Blocked by:** 05（前端依赖与运行时配置）、06（累计 API Client 生成与适配层）

**Status:** ready-for-agent

**外部前置：** 票 05、06 交付；宿主身份与两个菜单子项由负责人在权限系统配置
