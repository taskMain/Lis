# 03: 金额查询读模型

**What to build:** 两个页面各自的列表查询。行集由该组织的互认配置驱动，金额按四个业务键左连接；没有金额记录的行按「未配置」返回（当前金额无业务值，不用 0 冒充）。返回标准项目编码与名称、项目类型、分类名称、分组名称、组织名称、医院名称、院区名称、当前金额、金额已配置、互认配置状态、当前不可用原因；不返回组织/医院/院区编码，也不返回最后修改时间与最后修改人。按标准项目编码升序，不分页。组织、医院、院区与标准项目名称一次性批量读取后在内存映射填充，调用次数不随返回行数增长。当前不可用原因只表达标准目录停用，按分类、分组、标准项目顺序取首条；配置自身停用不占用该字段。查询不产生写入、审计事件或消息。

**Blocked by:** 01（外部组织服务接入与组织路径解析）

**Status:** ready-for-agent

**外部前置：** 票 01 交付的包引用与实测构建；真实数据库面另需负责人建表（见票 04）

- [ ] 行数等于该组织已建立互认配置的标准项目数；未配置行金额已配置为假、当前金额为空（V17）
- [ ] 返回字段集合与设计一致：无三个编码、无最后修改时间与最后修改人、四个名称齐全（V18）
- [ ] 名称与归属的读取次数不随返回行数增长（V19，10 行与 100 行两组计数替身断言）
- [ ] 按标准项目编码升序；无互认配置时成功返回空集合（V20）
- [ ] 三层全部启用时原因为空；仅分类、仅分组、仅标准项目停用时分别返回对应文案；多层时按分类、分组、标准项目取首条；配置自身停用不产生目录原因（V21）
- [ ] 医院管理员入口请求院区不属于可信医院即拒绝，不返回其他医院数据、不降级为空集合（V22）
- [ ] 平台管理员入口按请求的组织、医院、院区执行，不要求等于可信上下文组织；跨组织真实宿主面按 `S3-D20` 以应用层证据取证，宿主面记 `Blocked`，登记见宿主链路验收票（V29 应用层面）
- [ ] 内部投影携带三层启用状态用于派生原因，公共返回不泄漏这三层原始字段（V18）
- [ ] 查询 SQL 保持 Provider 中立，不使用方言写法；读模型不承担写入职责
- [ ] 先建立目标失败证据或等价基线；完成适用影响分析
