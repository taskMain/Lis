# 阶段 3 前端测试矩阵

本文件只记录测试前计划，不记录通过结果。实际执行命令、结果、证据与残余风险写入 [阶段测试报告](../testReport.md)。环境值引用项目环境规范，不在此复制。

两个页面分别为平台管理员页「互认项目金额维护」（路由 `recognition-amounts`）与医院管理员页「本院区互认项目金额」（路由 `branch-recognition-amounts`）；两条宿主链路都必须从宿主登录页与宿主菜单进入。矩阵条目与 S3-D22～S3-D29 及 [Client/design.md](design.md) 现行口径一致。
