# 15: 医院管理员页与可信范围

**What to build:** 交付医院管理员查看本院报告与历史版本的那个页面（含路由与菜单名登记），其与平台管理员页的差异只在取值来源与范围固定：组织与医院取自令牌可信上下文并固定展示（对应级不渲染下拉、请求不提交组织与医院），只让院区可选且院区必须属于可信医院。从宿主菜单进入该页的验收由票 12 承接，本票交付到「路由与菜单名称已登记、路由接入完成、页面行为可用」为止。可信组织或医院缺失时页面给出阻断提示、不渲染院区选择、不发业务请求，不伪造组织、不降级为空值。院区切换时清空上一范围的数据与未提交筛选并回到第 1 页；不属于可信医院的院区由服务端拒绝，页面不做本地归属判断。列表、分页、详情与只读历史版本、枚举展示、下载与四类失败态的行为与平台管理员页一致，复用同一套列表与详情组件，仅取值来源与范围固定不同。

**Blocked by:** 13（累计 API Client 生成与适配层）、14（平台管理员页）

**Status:** ready-for-agent

**外部前置：** 路由字符串与菜单名称在页面实现阶段确定后登记；权限系统的菜单子项与角色授权由负责人配置（宿主验收在票 12）；上述前置未就绪时，依赖该前置的勾选项在阶段报告记 `Blocked`，其余未执行项记 `NotRun`

- [ ] 医院管理员页的组织与医院固定展示且请求不提交；可信上下文缺失时阻断页面、不发业务请求、不伪造组织（C23）
- [ ] 院区可选且切换时清空上一范围的数据与未提交筛选并回到第 1 页；院区不属于可信医院时由服务端拒绝，页面不做本地归属判断（C24）
- [ ] 列表与详情复用同一套组件，仅取值来源不同；筛选、分页与排序行为与平台管理员页一致（C25）
- [ ] 页面失败态与平台管理员页一致：保留数据、结束加载、允许重试、无本地错误提示（C26）
- [ ] 页面无任何写操作入口；不在页面创建客户端；不把敏感条件写入地址栏（C23–C26，以及无矩阵编号的适配层约束）
- [ ] 路由字符串与菜单名称已确定并登记；路由接入完成，可进入页面（宿主菜单可达性由票 12 验收）（C27 的路由面）
- [ ] `git diff --check` 干净；证据记入阶段测试报告（无矩阵编号）

**口径：** 本票覆盖层级为页面与组件的组件层（C23–C26）；宿主链路验收与真实归属拒绝由票 12 承接。矩阵编号可跨批次引用，按完整用例只统计一次，只完成部分层级不记为通过。
