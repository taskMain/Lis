# 17: 自动端点清单断言

**What to build:** 在本阶段新增端点全部落地之后，把自动端点清单断言锁定为本阶段新增后的完整清单，并保持「只收紧、不放宽」的方向。清单需要覆盖既有的 26 条业务端点加上本阶段新增的全部自动端点——两个提交入口方法、两个作废方法各由框架按接口自动暴露为端点（共 4 条），另加两个列表查询、版本列表查询、版本详情查询，以及手写控制器的两个上传动作与两个下载动作；断言不再接受宽松匹配（例如只断言前缀、只断言数量下限或只断言子集）。手写控制器动作的路由不得与既有自动端点前缀冲突，这一点同时由本票核对：路由与既有自动端点清单不重复、不遮蔽。

**Blocked by:** 05（报告与版本基础链路）、08（管理端报告列表查询与 PDF 下载）

**Status:** ready-for-agent

**外部前置：** 无（断言基于端点声明与路由，不需要启动宿主；如改为从运行中的宿主取端点清单，按项目环境规范登记的本地后端端口与测试身份执行）；上述前置未就绪时，依赖该前置的勾选项在阶段报告记 `Blocked`，其余未执行项记 `NotRun`

- [ ] 自动端点清单断言覆盖本阶段新增后的完整清单，且不再接受宽松匹配（V83 的端点清单面）
- [ ] 清单包含两个提交入口与两个作废方法的自动端点（共 4 条）、两个列表查询、版本列表查询与版本详情查询（V83 的端点清单面）
- [ ] 手写控制器动作的路由纳入核对范围，且与既有自动端点清单不重复、不遮蔽（V83 的路由面）
- [ ] 断言在既有测试套件中真实执行，失败会准确指出端点清单偏差（V83）
- [ ] 未删除、跳过或放宽任何既有有效断言（无矩阵编号，属断言纪律）
- [ ] `git diff --check` 干净；证据记入阶段测试报告（无矩阵编号）

**口径：** 本票覆盖层级为既有断言的源码契约面（V83 的端点形态与清单核对面）；接口的真实行为由票 05、08 承接，宿主面由票 12 承接。矩阵编号可跨批次引用，按完整用例只统计一次，只完成部分层级不记为通过。
