# 06b: 检查报告完整内容

**What to build:** 在本票的范围内承接批次 3：让检查报告与检验报告共用同一条提交与作废链路，并补齐检查专项内容、检查项目与检查部位的完整写入。检查报告提交与检验报告同一形态：multipart 两部件、成功返回布尔真、管理器内分步写入并最后登记事件、失败不保存任何内容。专项内容侧需落实：检查所见与检查结论必填（完整原文）、来源诊断名称必填、实际检查时间必填、检查医生 ID 与名称必填且成对；来源影像状态为应填（源系统能够判断时必须提供，不能判断时填未知，仅接受三值），字段未提供时按未知处理并保存、不拒绝整份报告；影像调阅地址在无影像时必须为空、有影像而未提供地址时仍可接收；检查项目至少一条、来源项目名称必填（互认项目编码缺失不影响接收）；检查部位名称必填、项目没有明确部位时部位集合可为空；报告级内容按原文保存、不拆分到项目；检查医生与报告医生可为同一人。检查报告作废与检验报告同口径。

**Blocked by:** 05（报告与版本基础链路）

**Status:** ready-for-agent
