# 请求样例：完整检验报告

本文件是阶段 4 两个提交接口的验收请求样例之一，按 SRS F03.2 与 UML1 的请求值对象逐字段构造，供票 12 的接口直测与页面验收使用；字段填报要求以 [Server/design.md](../Server/design.md) 的「提交请求字段」章为正式载体，本文件只给出可用样例。

调用方式：`multipart/form-data`，文本部件名 `reportJson` 承载下面 JSON 文档原文，文件部件名 `pdfFile` 承载 PDF 文件流；端点 `POST /api/v1/report-pdf/laboratory-report`，需携带宿主签发的 Bearer token。

样例覆盖的边界：普通结果两条（一条含互认项目编码与检测人、一条互认项目编码与检测人为空）；细菌鉴定结果两条（一条检出具体菌种并挂两条药敏结果、一条按未检出表达且药敏集合为空）；应填字段部分提供、部分留空。时间取值使申请时间不晚于报告时间、报告时间不晚于审核时间，且报告时间不晚于提交时的平台接收时间。
