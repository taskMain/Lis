# 请求样例：完整检查报告

本文件是阶段 4 两个提交接口的验收请求样例之一，按 SRS F03.3 与 UML1 的请求值对象逐字段构造，供票 12 的接口直测与页面验收使用；字段填报要求以 [Server/design.md](../Server/design.md) 的「提交请求字段」章为正式载体，本文件只给出可用样例。

调用方式：`multipart/form-data`，文本部件名 `reportJson` 承载下面 JSON 文档原文，文件部件名 `pdfFile` 承载 PDF 文件流；端点 `POST /api/v1/report-pdf/examination-report`，需携带宿主签发的 Bearer token。

样例覆盖的边界：来源影像状态为有影像且提供调阅地址；检查项目两条，其中一条挂两个检查部位、另一条部位集合为空（项目没有明确部位）；互认项目编码部分提供、部分留空；检查医生与报告医生为同一人。时间取值使申请时间不晚于报告时间、报告时间不晚于审核时间，且报告时间不晚于提交时的平台接收时间。
