# 13: 累计 API Client 生成与适配层（含提交与作废端点）

**What to build:** 让前端能用与本阶段后端契约一致的生成客户端与稳定适配层，且不提前纳入后续阶段能力。生成按累计规则执行：保留阶段 1–3 已交付接口，加入本阶段稳定契约（两个作废端点、两个提交端点、两个列表查询、版本列表查询、版本详情查询、按报告标识与版本标识取文件流的下载端点），排除后续阶段端点与登录接口；生成前核对累计清单，生成后核对公开入口、请求与读模型字段、可空性、枚举、分页形状与无残留后续端点，并恢复被生成覆盖的手写入口文件；生成过程不提交本机路径、日志或临时文件。生成必须在后端全部契约稳定后执行——本票因此以报告与版本基础链路、检验与检查两类完整内容、以及管理端查询与下载三面为前置。适配层负责把生成的请求与读模型转换为稳定视图模型：请求侧筛选条件与分页参数按契约嵌套提交、空值归一正确、患者证件号码与姓名按用户输入原样提交（不做本地大小写或空白改写）、不把敏感条件写入地址栏；响应侧分页收敛为页面分页模型并校验页码、页容量与总数（总数须为安全整数且非负，非法即按契约错误处理、不伪造分页状态）；下载使用已鉴权客户端取二进制、按版本保存的下载名触发保存、释放对象地址、失败不产生本地错误提示。

**Blocked by:** 00（UML2 上游同步）、05（报告与版本基础链路）、06a（检验报告完整内容）、06b（检查报告完整内容）、08（管理端报告列表查询与 PDF 下载）

**Status:** ready-for-agent

**外部前置：** 生成命令与配置使用项目既有方式；上述前置未就绪时，依赖该前置的勾选项在阶段报告记 `Blocked`，其余未执行项记 `NotRun`

- [ ] 生成包的公开入口完整，请求与读模型字段、可空性、枚举与分页形状与后端契约一致（C1、C2）
- [ ] 累计范围正确：阶段 1–3 已交付接口保留、登录接口仍被排除、无后续阶段端点泄漏、无退化类型或残留占位模型（C1、C2）
- [ ] 手写入口文件在生成后被核对并恢复；生成未提交本机路径、日志或临时文件（C1）
- [ ] 生成包与应用均可构建、类型检查通过（C3）
- [ ] 适配层请求映射：筛选与分页按契约嵌套提交、空值归一正确、患者证件号码与姓名原样提交、敏感条件不进地址栏（C4）
- [ ] 适配层分页响应收敛：合法响应收敛为页面分页模型；页码小于 1、页容量小于 1、总数负数或非安全整数一律按契约错误处理，不伪造分页状态（C5）
- [ ] 适配层读模型映射：报告类型、状态、版本状态与文本字段正确映射；患者字段与 PDF 文件名映射正确；缺失字段有稳定兜底（C6）
- [ ] 分页控件配置：页容量可选值域与服务端一致、显示记录总数、改变页容量回到第 1 页、加载中禁用；不在页面内联分页对象（C7）
- [ ] 范围切换重置：切换组织、医院或院区时清空旧范围的数据与未提交筛选并回到第 1 页（C9）
- [ ] 过期响应丢弃：连续操作时只采纳最后一次请求结果，过期响应被丢弃（C10）
- [ ] 下载处理：使用已鉴权客户端取二进制、按报告标识与版本标识请求、按版本保存的下载名触发保存、释放对象地址、失败不产生本地错误提示（C8）
- [ ] 页面不直接扩散生成的类型；不在页面创建客户端；未新增前端第三方依赖（C1，以及无矩阵编号的依赖边界约束）
- [ ] `git diff --check` 干净；证据记入阶段测试报告（无矩阵编号）

**口径：** 本票覆盖层级为客户端契约与适配层的组件层（C1–C10，其中 C3 的矩阵层级为 `Static`）；页面行为由票 14、15 承接，宿主面由票 12 承接。矩阵编号可跨批次引用，按完整用例只统计一次，只完成部分层级不记为通过。
