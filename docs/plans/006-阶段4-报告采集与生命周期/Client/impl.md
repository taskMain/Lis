# 阶段 4 前端实施方案

设计见 [design.md](design.md)，跨端批次见阶段根 [impl.md](../impl.md)，测试前矩阵见 [testPlan.md](testPlan.md)，结果见阶段根 [testReport.md](../testReport.md)。

本文件只记录本端实施批次与执行顺序，不复制测试矩阵。

## 批次

| 批次 | 范围 | 前置 | 矩阵编号 |
|---|---|---|---|
| C1 | API Client 累计重生成与契约核对 | 后端批次 1-3 契约稳定 | C1-C3 |
| C2 | 适配层与视图模型、分页状态处理、PDF 下载处理 | C1 | C4-C10 |
| C3 | 平台管理员页：筛选区、列表、分页、详情与只读历史版本 | C2 | C11-C22 |
| C4 | 医院管理员页：可信范围固定、院区可选、列表与详情 | C2、C3（复用组件） | C23-C26 |
| C5 | 路由接入、宿主链路验收与阶段报告 | C3、C4；菜单配置 | C27-C31 |

## 执行顺序

1. C1 在后端契约稳定后执行：先取后端 OpenAPI 并固化，再生成，再核对公开入口、字段、可空性、分页形状与手写入口文件。
2. C2 建立稳定适配层后才进入页面实现；页面不直接使用生成的类型。
3. C3 与 C4 共用同一套列表与详情组件，医院管理员页只覆盖取值来源差异与范围固定行为。
4. 每个页面先建立页面级失败态与分页行为的失败证据，再补齐成功路径。
5. C5 从宿主登录页与菜单进入完成真实验收；本地直达、构建成功与接口直测不替代宿主验收。

## 交接

- 两个页面的路由字符串在 C3/C4 实现完成时确定，并在阶段根 `impl.md` 与宿主菜单配置中登记。
- 页面不新增本地接口错误提示、不解析错误响应体、不新增请求拦截器；错误展示由宿主统一处理。
- 报告提交接口在管理端不提供上传界面。
