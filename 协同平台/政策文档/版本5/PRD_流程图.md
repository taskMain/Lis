## 图1：申请全生命周期（主流程）

```mermaid
flowchart TD
    A["外部接入系统<br>通过接口创建申请"] --> B["平台生成申请单号<br>申请状态=有效<br>样本轮次=第1轮<br>样本主状态=待送出"]

    B --> C{"是否打包？"}

    C -->|"不打包<br>（可选流程）"| D["按条码/申请送出"]
    C -->|"打包（可选流程）"| C1["创建包<br>加入样本"]
    C1 --> C2{"包内样本<br>是否满足送出条件？"}
    C2 -->|"是"| D1["按包送出"]
    C2 -->|"否<br>（样本被移出/不满足条件）"| C3["调整包内样本"]
    C3 --> C2

    D --> E["生成送出记录<br>样本主状态=已送出"]
    D1 --> E

    E --> F{"接收方核对"}

    F -->|"正常接收"| G["样本主状态=已接收<br>生成接收记录（正常）"]
    F -->|"异常接收"| G1["样本主状态=已接收<br>生成接收记录（异常）<br>生成异常记录→图2"]
    F -->|"未到货"| G2["样本主状态=已送出（不变）<br>生成接收记录（未到货）<br>生成异常记录→图2"]

    G --> H{"接收方回传<br>检测开始？"}
    H -->|"是（可选）"| H1["样本主状态=检测中"]
    H -->|"否<br>（可直接跳过）"| I
    H1 --> I

    G1 --> G1X{"异常处理结果？"}
    G1X -->|"继续检测/关闭异常"| H
    G1X -->|"退回/损毁/无法检测"| G1Y["当前轮次=已终止流转<br>发起机构可重新送检"]

    I["上传方通过接口<br>上传报告PDF"] --> J["生成报告版本号<br>样本主状态=检测完成"]

    J --> K{"审核开关<br>是否启用？"}

    K -->|"启用"| L["报告状态=待审核"]
    K -->|"未启用"| M["报告状态=已发布<br>自动发布"]

    L --> N{"接收方管理人员<br>审核"}
    N -->|"审核通过"| M
    N -->|"审核不通过"| N1["报告状态=审核不通过<br>上传方可再次上传报告"]

    M --> O["触发报告发布推送<br>报告对发起机构可见"]

    O --> P["发起机构用户<br>查询/下载报告"]
```

## 图2：样本异常处理分支

```mermaid
flowchart TD
    A["样本异常"] --> B{"异常来源？"}

    B -->|"异常接收<br>（接收时当场发现<br>实物存在但有问题）"| C["样本主状态=已接收<br>生成异常记录<br>状态=待处理"]
    B -->|"未到货<br>（送出记录有、实物没有）"| D["样本主状态=已送出（不变）<br>生成异常记录<br>来源=未到货，状态=待处理"]
    B -->|"已接收后人工登记<br>（接收后才发现问题<br>样本已进入实验室）"| H{"当前样本阶段？"}

    H -->|"样本处于已接收<br>（尚未开始检测）"| C
    H -->|"样本处于检测中<br>（样本已消耗）"| H1["异常记录<br>来源=已接收后人工登记<br>状态=待处理<br>处理结果限制见下方"]
    H -->|"样本处于检测完成<br>（检测已结束）"| H2["异常记录<br>来源=已接收后人工登记<br>状态=待处理<br>仅可选「关闭异常」"]

    C --> C1{"选择处理结果"}

    C1 -->|"继续检测"| C2["解除检测阻断<br>异常记录自动关闭<br>样本进入检测流程"]
    C1 -->|"关闭异常"| C3["解除检测阻断<br>异常记录关闭<br>样本进入检测流程"]
    C1 --> C4a["退回样本"]
    C1 --> C4b["样本损毁"]
    C1 --> C4c["无法检测"]

    C4a --> C4["当前轮次=已终止流转<br>异常记录自动关闭<br>发起机构可重新送检"]
    C4b --> C4
    C4c --> C4

    H1 --> H1a{"选择处理结果<br>（退回/损毁不适用）"}
    H1a -->|"继续检测"| C2
    H1a -->|"关闭异常"| C3
    H1a -->|"无法检测"| C4

    H2 --> H2a["仅可选「关闭异常」<br>异常记录关闭<br>样本保持检测完成"]

    D --> D1{"线下确认<br>实物情况"}

    D1 -->|"延迟到货"| D2["样本到达后<br>变更样本级处理结果<br>（未到货→正常/异常接收）<br>异常记录手动关闭"]
    D1 -->|"未实际送出/登记错误"| D3["走送出撤回<br>样本回到待送出<br>重新送出<br>异常记录手动关闭"]
    D1 -->|"包漏装漏送"| D4["走补送流程<br>生成补送记录<br>异常记录手动关闭"]
    D1 -->|"运输丢失"| D5["当前轮次=已终止流转<br>异常记录自动关闭<br>发起机构可重新送检"]

    D5 --> E["发起机构<br>发起样本重新送检"]
    C4 --> E

    E --> F["生成新样本轮次<br>样本主状态=待送出<br>成为当前流转轮次"]

    C2 --> G["进入正常检测流程"]
    C3 --> G
    D2 --> G
```

## 图3：报告版本管理状态机

```mermaid
stateDiagram-v2
    [*] --> 待审核: 上传成功<br>（审核开关启用）
    [*] --> 已发布: 上传成功<br>（审核开关未启用）

    待审核 --> 已废弃: 上传方主动再次上传
    待审核 --> 已发布: 审核通过
    待审核 --> 审核不通过: 审核不通过
    待审核 --> 已失效: 终止申请联动

    审核不通过 --> 已废弃: 上传方再次上传
    审核不通过 --> 已失效: 终止申请联动

    已发布 --> 已替代: 新版本发布
    已发布 --> 已作废: 人工作废/终止申请联动

    已作废 --> 待审核: 再次上传（非终止原因）
    已作废 --> 已发布: 再次上传（非终止原因<br>审核开关未启用）

    note right of 已发布: 当前有效报告<br>对发起机构可见<br>可查询、可下载、可推送<br>再次上传产生新版本
    note right of 已替代: 历史版本<br>仅版本追溯可见<br>不可作为再次上传来源<br>再次上传应基于当前有效报告
    note right of 已作废: 已作废版本<br>不可下载<br>非终止原因可再次上传<br>终止申请联动不可再次上传
    note right of 已失效: 从未发布过<br>因终止申请退出<br>不可审核/发布/查询/推送<br>不可再次上传
    note right of 已废弃: 被新上传版本替代<br>不可审核/发布/查询/推送<br>不可再次上传
```

## 图4：终止申请联动处置

```mermaid
flowchart TD
    A["发起机构<br>（接口或页面）<br>发起终止申请"] --> B["申请状态=已终止<br>立即生效，不可恢复"]

    B --> C{"判定终止类型<br>（系统自动判定）"}

    C --> C1["未送出取消<br>（样本仍为待送出）"]
    C --> C2["送出后终止<br>（样本已送出未接收）"]
    C --> C3["接收后终止<br>（样本已接收未进入检测）"]
    C --> C4["检测中终止<br>（样本处于检测中）"]
    C --> C5["检测完成后终止<br>（检测完成无当前有效报告）"]
    C --> C6["报告后终止<br>（已存在当前有效报告）"]

    B --> D["阻断后续业务"]
    D --> D1["不允许继续打包"]
    D --> D2["不允许继续送出"]
    D --> D3["不允许继续接收<br>（接收时拦截+记录）"]
    D --> D4["不允许检测推进"]
    D --> D5["不允许上传报告"]
    D --> D6["不允许审核发布报告"]
    D --> D7["不允许新推送"]
    D --> D8["不允许发起重新送检"]

    B --> E["包联动"]
    E --> E1["该申请样本<br>从所有未送出包中<br>自动移出"]
    E1 --> E2["包创建者收到<br>「包内样本因终止被阻断」通知"]

    B --> F["报告联动"]
    F --> F1{"当前报告状态？"}
    F1 -->|"已发布（当前有效）"| F2["系统自动标记为已作废<br>作废原因=终止申请"]
    F1 -->|"待审核"| F3["系统自动标记为已失效"]
    F1 -->|"审核不通过"| F3
    F1 -->|"已替代/已废弃/已作废"| F4["不再处理<br>（历史版本）"]

    B --> G["样本与条码"]
    G --> G1["样本主状态<br>保持终止时状态不变"]
    G --> G2["原样本条码<br>不可用于创建新申请"]

    B --> H["触发通知"]
    H --> H1["接收方人员：申请已终止"]
    H --> H2["发起机构用户：报告已作废<br>（如有当前有效报告）"]
    H --> H3["终止申请推送通知<br>（当前版本不做）"]

    B --> I["记录留痕"]
    I --> I1["终止类型（系统判定）"]
    I --> I2["终止原因（发起机构选择）"]
    I --> I3["终止时间、发起方、操作来源"]
    I --> I4["终止时样本主状态"]
    I --> I5["终止时报告状态摘要"]
```

## 图5：危急值处理闭环

```mermaid
flowchart TD
    A["上传方随报告<br>提交危急值信息"] --> B["危急值记录生成<br>关联申请+样本条码+报告版本<br>平台内部状态=待处理"]

    B --> C{"报告审核开关？"}

    C -->|"启用"| D["报告待审核<br>危急值不对外"]
    C -->|"未启用"| E["报告自动发布<br>危急值进入可推送状态"]

    D --> F{"报告审核结果？"}
    F -->|"审核通过"| E
    F -->|"审核不通过"| F1["危急值不对外<br>等待再次上传报告"]

    E --> G["触发危急值发布推送<br>（向发起机构）"]

    G --> H["发起机构<br>收到危急值通知"]

    H --> I{"医院侧处理"}
    I --> J["医院系统回传处理回执<br>或平台人工登记回执"]

    B --> K["平台内部处理<br>（接收方具备权限的用户）"]

    K --> K1{"选择处理结果"}

    K1 --> K1a["已电话通知"]
    K1 --> K1b["已人工确认"]
    K1 --> K1c["无需进一步处理"]
    K1 --> K1d["已失效关闭"]
    K1 --> K1e["其他<br>（处理说明必填）"]

    K1a --> K2["状态=已处理"]
    K1b --> K2
    K1c --> K2
    K1d --> K2
    K1e --> K2

    K2 --> L["处理记录留痕<br>不可修改、不可删除<br>只允许追加"]

    J --> M["医院侧回执记录<br>独立于平台内部处理状态"]

    B --> N{"报告版本<br>有效性变化？"}

    N -->|"报告作废"| O["危急值退出当前有效范围<br>触发危急值失效通知"]
    N -->|"报告被替代"| O
    N -->|"终止申请联动"| O

    O --> P{"平台内部<br>处理状态？"}
    P -->|"待处理"| Q["进入「已失效待处理」筛选<br>用户可手动关闭<br>（选择已失效关闭）"]
    P -->|"已处理"| R["历史详情保留<br>不再变更"]

    M --> S["危急值详情页展示<br>平台处理状态+医院回执状态<br>两者独立，不互相替代"]
```
