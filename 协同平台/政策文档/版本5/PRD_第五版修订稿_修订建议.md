## 1. 1.5 样本接收管理 修订

### 1.5.6 接收异常处理路径 **【重写】**

**【删除】** 原文 1.5.6 全部删除。

**【新增】** 替换为以下内容：

#### 1.5.6 接收结果分类

接收方核对送出记录中的样本清单，对每个样本逐项给出处置结果。接收结果分为三类：

1. **正常接收**：实物符合，确认接收。样本进入已接收。

2. **异常接收**：实物存在但有问题（样本破损、条码无法识别、样本不符、容器不符等），先收下，同时登记异常记录。样本进入已接收。异常记录未关闭时，默认阻断检测流程。

3. **未到货**：送出记录中有但实物没有（漏送）。样本不进入已接收，停留在已送出状态。生成异常记录，标记为未到货。后续由送方和接收方线下确认后处理——如确已送出但丢失走补送或机构重新采样，如未实际送出走送出撤回。

接收结果对样本主状态的影响：

| 接收结果 | 样本主状态 | 异常记录 |
|----------|-----------|----------|
| 正常接收 | 已送出 → 已接收 | 无 |
| 异常接收 | 已送出 → 已接收 | 有，未关闭则阻断检测 |
| 未到货 | 停留在已送出 | 有，标记为未到货 |

关键规则：

1. 接收异常不导致申请终止。申请保持有效，机构可重新采样、重新送出，继续完成剩余流程。
2. 异常类型、异常描述、发现时间、发现人或调用系统、处理意见均应记录。
3. 接收结果的后续处理路径在样本异常处理章节（1.6）定义。

---

#### 1.6.5 异常接收后的样本处理

异常接收（实物存在但有问题）：样本主状态进入已接收，同时生成异常记录。异常记录处于待处理状态时，默认不允许进入检测中或检测完成。

处理路径：

1. 异常记录未关闭 → 阻断检测。样本停留在已接收。
2. 异常处理结果为"继续检测" → 解除阻断，样本进入检测流程。
3. 异常已关闭且未标记终止处理 → 解除阻断，样本进入检测流程。
4. 异常处理结果为"退回样本"或"终止处理" → 永久阻断，不允许继续检测。

---

#### 1.6.6 未到货后的样本处理 **【新增】**

未到货（漏送）：样本不进入已接收，停留在已送出状态，生成异常记录（异常来源=未到货）。

处理路径：

1. 送方和接收方线下确认实物情况。
2. 如确已送出但丢失：机构可重新采样、用新条码重新创建申请；或走补送流程（样本仍为待送出且满足补送条件时）。
3. 如送方未实际送出：走送出撤回（1.4.7），样本回到待送出后重新送出。
4. 异常处理结果为"关闭异常"：未到货已核实并完成处理，异常关闭，不影响样本后续流转。
5. 未到货的异常处理不自动终止申请。

（后续章节 1.6.6 到 1.6.8 顺延编号。）

### 1.6.9 异常处理结果与申请终止的联动 **【新增】**

1. 异常处理结果中的"退回样本"和"终止处理"表示样本层面不再继续后续检测或报告流程，但**不自动触发申请终止**。
2. 申请终止是独立流程，由以下方式触发：
   - 发起机构主动发起申请终止（任意阶段）。
   - 异常处理完成后，由有权限人员（接收方或平台）根据业务判断，手动触发申请终止。
3. 以下场景建议人工判断是否需要终止申请：
   - 样本已破损且机构无法重新采样 → 申请终止。
   - 未到货已确认且机构无需重新送检 → 申请终止。
   - 样本可重新采样重新送检 → 不终止申请，机构走新采样+新条码路径。
4. 异常处理记录中应能关联后续触发的申请终止记录，用于追溯。

### 1.6.10 异常处理记录追加规则 **【新增】**

1. 异常处理记录一旦生成，不允许修改或删除。
2. 如需补充说明或修正，只能追加新的处理记录。
3. 追加记录字段规则：

| | 首次处理记录 | 追加记录 |
|------|------|------|
| 处理结果 | **必填** | 不可选（沿用原处理结果） |
| 处理说明 | 可选 | **必填** |
| 处理人 | 必填 | 必填 |
| 处理时间 | 必填 | 必填 |

4. 追加记录不改变原始处理结果。
5. 危急值处理记录（1.10）统一适用此规则。
